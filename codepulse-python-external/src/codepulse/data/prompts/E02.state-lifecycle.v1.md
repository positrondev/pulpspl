QUESTION: This LangGraph node overwrites state keys that nodes defined in other modules also
write, with no reducer. Is each overwrite an intended hand-off, or can one node silently
discard another node's value?

An overwrite is intended when the graph's edges guarantee an order (the later node refines or
replaces the earlier value on purpose). It is a defect when the nodes can run in either order,
in parallel, or when the earlier value is still needed after this node runs.
